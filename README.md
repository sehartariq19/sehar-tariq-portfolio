# Sehar Tariq — Portfolio Website 1

Light, responsive, accessible single-page CV website.

## Run locally
Open `index.html` in a modern browser. All images and assets are local. Google Fonts use the internet but system fonts work offline.

## Sections
Home, About, Experience, Projects, Skills, and Contact. LinkedIn links use the profile provided by Sehar Tariq.

## GitHub Pages
Upload the files to the root of a repository, then select Settings → Pages → Deploy from branch → main / (root).

## Note
Please confirm the email and phone number against the original CV before publishing.
